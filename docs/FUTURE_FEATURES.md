# 후속 개발 로드맵

> 기준: 로컬 `recover` / `d333e3868e5bb94073030780ce0910a65b3ef4d8` / 2026-07-13

이 문서는 현재 기능 명세가 아니라 후속 단계의 방향만 기록한다. 구체적인 JSON 계약, React 구조, 풋살 Entity·테이블·API·요구사항은 아직 미결정이다.

```text
현재 코드 품질 정리
→ 게시판 REST API 전환
→ 성능 검증
→ React 전환
→ 풋살 매칭·예약 도메인 설계
→ 풋살 MVP
```

| 단계 | 상태 | 범위 |
| --- | --- | --- |
| 현재 코드 품질 정리 | 후속 단계 | M1에서 확인한 명명, Validation, Security, JPA, Pagination, 테스트·배포 부채 정리 |
| 게시판 REST API 전환 | 후속 단계 | 현재 SSR 동작을 기준으로 별도의 M2 계약 수립 |
| 성능 검증 | 아이디어 | 측정 시나리오와 목표 수치는 미결정 |
| React 전환 | 후속 단계 | REST 전환 이후 검토; 클라이언트 구조 미설계 |
| 풋살 매칭·예약 도메인 설계 | 후속 단계 | 게시판 현대화 이후 요구사항부터 새로 정의 |
| 풋살 MVP | 미결정 | 범위, 데이터 모델, 일정 모두 미결정 |

기존 문서에 있던 카테고리, 좋아요, 파일 첨부, 신고, 실시간 알림 등의 상세 설계는 현재 구현이나 승인된 로드맵이 아니므로 M1 문서에서 제거했다.
